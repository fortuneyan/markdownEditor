# Markdown Editor

一个功能完善的 Web Markdown 编辑器，支持实时预览、主题切换、多视图模式。

## 功能特性

### 核心功能
- **实时预览** - 编写 Markdown 时即时看到渲染效果
- **三种视图模式** - 编辑模式、预览模式、分屏模式
- **主题切换** - 支持明暗主题切换

### 编辑功能
- 行号显示，当前行高亮
- 字数统计
- 光标位置显示（行/列）
- 工具栏快捷操作：
  - 插入表格
  - 插入代码块
  - 插入标题、粗体、斜体、链接、列表

### 文件操作
- 上传 Markdown 文件
- 下载为 .md 文件
- 打印文档

### 高级特性
- Mermaid 图表支持（流程图、时序图等）
- ASCII Art 转 SVG 渲染
- 分屏滚动同步（源码与预览对应滚动）

## 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式与主题（CSS 变量）
- **JavaScript** - 交互逻辑
- **marked.js** - Markdown 解析与渲染
- **Mermaid.js** - 图表渲染

## 使用方法

直接在浏览器中打开 `index.html` 即可使用。
